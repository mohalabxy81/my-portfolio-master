Demo: https://stfly.vip/mohamedCV

## Eng. Mohamed Adel Nabih | Civil Site & Execution Engineer Portfolio

A modern, dark-themed portfolio website for a Civil Site & Execution Engineer with 5+ years of experience in roads, infrastructure, reinforced concrete, and interior/exterior finishing in Egypt.

### Features
- 🌙 Dark theme with glassmorphism design
- ✨ Smooth scroll-reveal animations
- 📱 Fully responsive (Bootstrap 5)
- 📊 Animated skill progress bars
- 🏗️ Project filtering by category
- 📄 Live PDF CV generation (html2pdf.js)
- 📬 Contact via WhatsApp & Email
- ♿ WCAG accessible (skip links, ARIA labels, focus-visible)
- 🔍 SEO optimized (JSON-LD, Open Graph, sitemap)

### Tech Stack
- HTML5, CSS3, Vanilla JS
- Bootstrap 5
- Font Awesome 6
- Slick Slider
- Typed.js
- html2pdf.js
